**NTC Task Manager — AI-Powered Task Management, Progress Analysis, Work Assignment & Results Tracking Platform

A full-stack academic task management platform developed for NTC – Narayan Tuition Classes, designed to provide a structured digital environment for task assignment, progress monitoring, work management, and results tracking.

Project Status: Core MERN application implemented. AI-powered analysis, advanced progress analytics, and Google Classroom integration are under development.

🚀 Key Features
🔐 JWT-based user authentication
👥 Role-based access control
📝 Task creation, updating, deletion, and completion
📌 Task status and progress tracking
📊 Dashboard and task statistics
💾 Persistent MongoDB data storage
🔒 Password hashing using bcrypt
⚡ RESTful backend APIs
📱 Responsive web interface
🛡️ Protected backend routes
