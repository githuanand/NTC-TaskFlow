# 🚀 NTC TaskFlow

NTC TaskFlow is a full-stack task management platform developed for **NTC – Narayan Tuition Classes** to organize, manage, and track academic tasks efficiently.

## 🌐 Live Demo

👉 [Launch NTC Task Manager](https://ntc-task-manager-frontend.vercel.app/)

## ✨ Features

* 🔐 JWT-based authentication
* 👥 Role-based access
* 📝 Create, update, and delete tasks
* ✅ Task completion and status tracking
* 📊 Dashboard and task statistics
* 💾 Persistent MongoDB storage
* 🛡️ Protected backend routes
* 📱 Responsive user interface

## 🛠️ Tech Stack

**Frontend**

* React
* Vite
* React Router
* Axios
* CSS

**Backend**

* Node.js
* Express.js
* Mongoose
* JWT
* bcryptjs

**Database**

* MongoDB Atlas

## 🔄 Workflow

```text
Login
  ↓
Dashboard
  ↓
Create / Manage Tasks
  ↓
Update Task Status
  ↓
Track Progress
```

## 🚀 Deployment

* **Backend:** Render
